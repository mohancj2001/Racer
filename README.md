# 🏎️ Racer

A fast-paced 2D car racing game built with **JavaFX**, featuring smooth controls, collision detection, increasing difficulty, and an engaging gameplay experience.

---

## 📖 Overview

**Racer** is a JavaFX-based desktop racing game where players control a car, avoid incoming obstacles, and survive as long as possible while achieving the highest score.

The project demonstrates Java game development concepts such as:

- JavaFX Animation
- Collision Detection
- Keyboard Input Handling
- Game Loop
- Object-Oriented Programming
- Resource Management

---

## ✨ Features

- 🚗 Smooth keyboard controls
- ⚡ Dynamic gameplay
- 💥 Collision detection
- 🏆 Score tracking
- 🎵 Sound effects
- 🌄 Background graphics
- 📈 Progressive difficulty
- 🖥️ Built entirely using JavaFX

## 🚀 Getting Started

### Run

Using Maven:

```bash
mvn clean javafx:run
```

Or run the `Launcher` class directly from IntelliJ IDEA.
